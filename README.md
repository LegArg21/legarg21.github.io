# Jogi érvelés a XXI. században Legal Argumentation in the 21st Century #
A kutatási program honlapja | Research project homepage

## A program leírása ##
A NKFI FK 138346 számon támogatott kutatási projekt 2021--2025 között a jogi érvelés XXI. századi változását vizsgálta, elméleti és gyakorlati szempontból egyaránt. Holnapunk röviden bemutatja a kutatás résztvevőit és eredményeit, valamint helyet ad a kutatási program folytatásából származó eredményeknek is.
